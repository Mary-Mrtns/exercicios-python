# — Lab de Programação

Esses são os exercícios que fiz na disciplina de Laboratório de Programação, no segundo semestre de Engenharia de Software. É basicamente meu
primeiro contato "de verdade" com Python: variável, laço, condicional,
sorteio aleatório, a base de tudo.

Resolvi subir aqui porque gosto de guardar meu progresso, mesmo os
exercícios mais simples.

## O que pratiquei aqui

- Variáveis e tipos (`int`, `float`, `str`, `bool`)
- Condicionais (`if` / `elif` / `else`)
- Laços `for` e `while`
- Sorteios e eventos aleatórios com `random`

## Os exercícios

| Arquivo | O que faz |
|---|---|
| `exercicio01.py` | Classificador de IMC |
| `exercicio02.py` | Tabuada interativa |
| `exercicio03.py` | Validador de senha |
| `exercicio04.py` | Jogo de adivinhação |
| `exercicio05.py` | Dados par ou ímpar |
| `exercicio06.py` | Sorteio de bingo simplificado |
| `exercicio07.py` | Calculadora de média escolar |
| `exercicio08.py` | Cara ou coroa |
| `exercicio09.py` | Verificador de números primos |
| `exercicio10.py` | Caixa eletrônico simplificado |

Os favoritos foram o do caixa eletrônico e o dos números primos, foram
os que mais me fizeram pensar antes de sair escrevendo código.

## Rodando

Cada exercício é um arquivo separado e independente:

```bash
python3 exercicio01.py
```

(é só trocar pelo nome do arquivo que quiser rodar)
